# Task Manager — сервис управления задачами с системой контроля версий

## Назначение

RESTful сервис для управления задачами с полным CRUD функционалом. Автоматически сохраняет историю всех изменений, поддерживает мягкое удаление и тегирование задач. Подходит для приложений, требующих отслеживания истории изменений и возможности восстановления данных.

---

## Архитектура и ключевые решения

- **REST API** — стандартные CRUD-эндпоинты на базе chi-роутера
- **Система контроля версий** — каждое изменение задачи сохраняется в отдельной таблице истории
- **Мягкое удаление (soft delete)** — задачи не удаляются физически, а помечаются как удалённые с возможностью восстановления
- **Теги** — поддержка категоризации и фильтрации задач
- **PostgreSQL** — надёжное хранение данных с транзакционной целостностью
- **Полный аудит** — фиксируется автор, время и тип каждого изменения

---

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/v1/tasks` | Получить список всех задач |
| POST | `/api/v1/tasks` | Создать новую задачу |
| GET | `/api/v1/tasks/{id}` | Получить задачу по ID |
| PUT | `/api/v1/tasks/{id}` | Обновить задачу (с сохранением истории) |
| DELETE | `/api/v1/tasks/{id}` | Мягкое удаление задачи |

---

## Результат

- Полный CRUD функционал с автоматическим сохранением истории изменений
- Мягкое удаление с возможностью восстановления
- Поддержка тегов для группировки и фильтрации задач
- Полный аудит всех операций (кто, когда, что изменил)
- Надёжное хранение в PostgreSQL с транзакционной поддержкой
- Middleware-логирование, recovery и request ID для отладки
| База данных | PostgreSQL |
| Хранение истории | отдельная таблица версий |
| Логирование | chi middleware |
